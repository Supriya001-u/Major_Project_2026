# Experimental Results & Evaluation Logging

## Overview
This directory stores empirical evaluation metrics, benchmark comparison tables, and execution logs recorded during Phase III experiments.

## Scientific Integrity Policy
- **No fabricated metrics:** Benchmark tables are only populated with experimental data observed from reproducible test executions.
- **Reproducibility:** Every logged experiment must record the input video sequence, target device (CPU/GPU), runtime FPS, counting error (MAPE), and average delay reduction.

## Files
- `benchmark_template.csv`: Standardized schema for logging Phase III empirical test runs.
- `evaluation_logs.csv`: Timestamped run-by-run telemetry.
